# Короткий prompt для другого чата

Считай это базовым universal rule для старта нового подпроекта.

В самом начале Орк должен создать минимальный набор документов:

- `*_readme.md`
- `*_decisions.md`
- `*_plan_index.md`
- `*_journal.md`
- `*_navigation.md`

Не разворачивай полный doc-set автоматически.
Не считай `battle_plan` обязательным первым артефактом.
Если для конкретного пилота нужен больший набор, сначала назови причину расширения.
